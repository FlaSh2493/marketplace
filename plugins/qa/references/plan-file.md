# 계획 파일 위치

`qa:run`이 시나리오를 찾을 때 읽는다. 계획 파일은 티켓 하나에 하나다. 한 티켓이 여러 레포를 건드려도 같은 파일에 레포별로 나눠 적는다.

## 둘 곳

- 계획은 Claude Code 플랜 모드로 쓴다. 파일은 Claude Code가 기본 플랜 위치(`~/.claude/plans/`)에 만든다. 모든 레포가 같은 위치를 쓰고, 레포에 커밋하지 않는다.
- 파일 이름은 Claude Code가 붙인다. 나중에 찾을 수 있게 첫 줄 제목에 티켓 키를 넣는다(`# <티켓 키> <티켓 제목>`). 티켓이 없으면 기능 이름을 넣는다.
- 계획이 원본이다. PR 본문은 계획에서 옮긴 결과물이다. 기준이 바뀌면 계획을 먼저 고친다.

## 찾을 폴더

- 기본은 `~/.claude/plans/`다.
- Claude Code 설정에 `plansDirectory`가 있으면 그 폴더도 본다. `~/.claude/settings.json`, 레포의 `.claude/settings.json`, `.claude/settings.local.json` 순서로 확인하고, 상대 경로는 레포 루트 기준이다. 이 설정이 있으면 Claude Code는 계획을 기본 위치가 아니라 그 폴더에 쓴다.

## 찾기

1. 대화에 이번 작업의 계획이 있으면 그것을 쓴다.
2. 사용자가 계획 경로를 주면 그 파일을 쓴다.
3. 없으면 티켓 키(인자, 대화, 브랜치 이름 순서)나 사용자가 말한 기능 이름으로 찾을 폴더의 파일 내용을 검색한다. 파일 이름은 정확히 맞지 않으므로 이름만 보지 않는다. 키 바로 뒤에 숫자가 이어지면 다른 티켓이다 — `ABC-123`을 찾을 때 `ABC-1234`가 들어 있는 파일은 후보가 아니다.
4. 후보가 둘 이상이거나 하나도 없으면 고르지 말고 사용자에게 묻는다.
5. 사용자가 계획이 없다고 확인하면 이슈의 수용 조건이나 사용자 요청을 출처로 쓰고, 어느 출처를 썼는지 결과에 적는다.
